## ⚡ Engineering highlights

### 🖥️ Full-stack product development

I build React interfaces in **TypeScript** for workflows that depend on backend APIs. I’ve modernized legacy features and used WebSockets for real-time updates. I think through loading, empty, and error states while defining the API contract so the UI can explain what happened and what the user can do next.

### 🔌 APIs, integrations, and background jobs

My backend experience spans **Node.js and Express** as well as **Python, FastAPI, Django, and Flask**. I’ve built REST APIs and microservices, worked with JWT authentication, and used Celery and asyncio for background and concurrent work. I’ve worked with PostgreSQL, MySQL, and MongoDB across application data layers.

### ☁️ Cloud delivery and test automation

I’ve worked with serverless workloads on **AWS and Azure**, containerized applications with Docker, and used Kubernetes and Jenkins in delivery workflows. I use pytest and unittest for Python testing and Cypress to exercise application flows in the browser.

## 🤝 How I work

- **Define the contract early.** Agree on what the API returns, how the UI handles failures, and how the data model supports the workflow.
- **Test behavior at the right level.** Cover service logic with focused tests and use browser tests for flows where several systems have to work together.
- **Plan for production.** Treat deployment, background-job failures, and diagnosis as part of delivering a feature.
